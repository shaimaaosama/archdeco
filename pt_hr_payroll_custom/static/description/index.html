Module Purpose

This module supports Hr Payroll Custom business workflow operations. It introduces and extends records around account payment register, hr payslip run, and hr payslip employees to support daily business operations. It provides operational interfaces such as Change Notification data, Create Payment, Cancel.

Key Features

  • Business screens and actions including Change Notification data, Create Payment.
  • Dedicated data models for account payment register, hr payslip run, and hr payslip employees.
  • Finance/payroll integration touchpoints for posting and settlement.
  • Configuration and master-data controls to match organization policy.

How To Use

  1. Confirm payslips for the period (batch run).
  2. Select multiple payslips in the list view.
  3. Use Register Payment from the Actions menu to open the payment wizard.
  4. Select the journal, payment date, and enter the memo, then confirm to create journal entries.
  5. The payslip form will show the Paid ribbon once payment is registered.
