PT Arch API

Premium Tech - API for posted customer invoices

About This Module

The `pt_arch_api` module exposes a protected REST endpoint that returns posted customer invoices with line details, taxes, and sales information.

Endpoint

GET /api/v2/pt_arch_api/invoices

Fields

Customer, Invoice Date, Products, Quantity, Price, Taxes, Totals, Sales Team, Sales Person
